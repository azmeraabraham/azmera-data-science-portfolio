# Credit Risk Predictive Analytics

## Business Question

Can borrower financial indicators be used to estimate the probability of default risk?

## Objective

Build a beginner-friendly classification model using borrower income, credit score, debt-to-income ratio, loan-to-value ratio, employment history, and loan amount.

## Tools

- Python
- Pandas
- scikit-learn
- Logistic Regression
- Model Evaluation Metrics

## Key Methods

- Data cleaning
- Feature selection
- Train/test split
- Logistic regression
- Accuracy, precision, recall, and confusion matrix

## Business Value

This project demonstrates applied machine learning fundamentals in a financial services context.
