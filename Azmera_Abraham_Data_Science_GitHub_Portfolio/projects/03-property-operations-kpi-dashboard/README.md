# Property Operations KPI Dashboard

## Business Question

How can ownership teams monitor portfolio performance across occupancy, revenue, renewals, delinquency, and operations?

## Objective

Create a business intelligence reporting structure for property operations and portfolio performance.

## Tools

- SQL
- Python
- Excel
- Tableau or Power BI

## Key Metrics

- Occupancy rate
- Renewal rate
- Delinquency rate
- Monthly revenue
- Maintenance tickets
- Average days to turn

## Business Value

This project connects directly to portfolio operations experience and demonstrates practical BI reporting for executive decision-making.
