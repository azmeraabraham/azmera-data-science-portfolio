# Housing Outcomes Dashboard

## Business Question

Which housing barriers most affect placement success and 90-day housing retention?

## Objective

Analyze participant-level housing support data to identify placement patterns, common barriers, and program effectiveness metrics.

## Tools

- SQL
- Excel
- Tableau or Power BI
- Python

## Key Metrics

- Placement rate
- Average days to placement
- 90-day retention rate
- Placement rate by county
- Primary barriers to housing
- Housing goal distribution

## Business Value

This project demonstrates how housing service programs can use data to evaluate outcomes, identify service gaps, and support program improvement.
