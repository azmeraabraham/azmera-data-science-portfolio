# OfferIntel Market Intelligence

## Business Question

How can residential real estate professionals use historical offer data to understand market competitiveness by ZIP code, price band, and week?

## Objective

Build an analytical framework that summarizes accepted offer behavior, offer-to-list ratios, days on market, seller concessions, appraisal gap usage, and contingency patterns.

## Tools

- Python
- SQL
- Pandas
- Tableau or Power BI

## Key Metrics

- Average offer-to-list ratio
- Median days on market
- Average offer count
- Inspection waiver rate
- Average seller credit
- Appraisal gap frequency
- Competitiveness score

## Business Value

This project demonstrates the type of analysis behind OfferIntel: translating raw transaction patterns into clear market intelligence that helps real estate professionals advise clients with data instead of guesswork.
