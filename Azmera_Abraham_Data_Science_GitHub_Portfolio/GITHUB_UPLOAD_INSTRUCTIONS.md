# GitHub Upload Instructions

## Recommended Repository Name

`azmera-data-science-portfolio`

## Step 1: Create the Repository

1. Go to GitHub.
2. Click **New Repository**.
3. Name it: `azmera-data-science-portfolio`.
4. Set it to **Public**.
5. Add the description:  
   `Data science and analytics portfolio featuring Python, SQL, business intelligence, and predictive analytics projects.`
6. Do not add a README if uploading this full folder as-is.

## Step 2: Upload Files

Option A: Drag-and-drop upload

1. Open the new repository.
2. Click **Add file**.
3. Click **Upload files**.
4. Drag all folders/files from this portfolio package into GitHub.
5. Commit changes.

Option B: Command line upload

```bash
git clone https://github.com/YOUR-USERNAME/azmera-data-science-portfolio.git
cd azmera-data-science-portfolio
cp -R /path/to/Azmera_Abraham_Data_Science_GitHub_Portfolio/* .
git add .
git commit -m "Add data science portfolio projects"
git push origin main
```

## Step 3: Pin the Portfolio

After uploading:

1. Go to your GitHub profile.
2. Click **Customize your pins**.
3. Pin `azmera-data-science-portfolio`.

## Step 4: Create a Profile README

Create a second repository with the exact same name as your GitHub username.  
Add the contents of `profile_README_for_GitHub.md` as the README file.

This will make your GitHub profile look polished when recruiters visit it.
